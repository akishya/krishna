# GitaGuru

GitaGuru is a personalized Bhagavad Gita wisdom application featuring an AI voice (Lord Krishna) and all 18 chapters of the Gita.

## Project Structure
- `assets/`: Images, icons, fonts, and audio files
- `css/`: Modularized CSS stylesheets
- `js/`: Modularized JavaScript files
- `index.html`: The main entry point

## Setup
Just open `index.html` in your browser.
